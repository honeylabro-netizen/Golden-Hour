# Golden Hour Website

Golden Hour is a static, Philippine-focused emergency learning guide for students and the general public.

Open `index.html` directly or use VS Code Live Server. The site includes four linked learning modules, local checklist storage, scenario practice, searchable guides, a source-review boundary for educational content, and a service worker for cached core pages.

Before publication, review every medical statement and hotline against the responsible authoritative source, then replace the review-status text with the actual review date. No downloadable PDF is included until a real, reviewed file is generated.
