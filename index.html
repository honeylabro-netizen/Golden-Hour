Core concept

First 60 seconds

The first minute can be critical. Know your first actions. This is a learning visualization, not a countdown.

60SECONDS
  1. 01Stay as calm as possible.
  2. 02Check whether the area is safe.
  3. 03Assess the immediate danger.
  4. 04Call appropriate emergency services.
  5. 05Give basic help only when safe.
  6. 06Follow dispatcher instructions.
